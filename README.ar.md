# Hauppauge Live Capture Studio

برنامج Windows مستقل (EXE) لالتقاط الفيديو الحي من جهاز **Hauppauge USB-Live2 (UPC00610)**، مع التقاط الصور (Snapshots) وتسجيل **MP4 / H.264 بدون صوت إطلاقاً**، وبأقل تأخير ممكن.

English: [README.md](README.md) · خطوات الاختبار: [TESTING.md](TESTING.md)

## ⚠️ حالة المشروع — اقرأ هذا أولاً

- شيفرة المصدر **كاملة** (C# / .NET 8 / WinForms / DirectShow)، لكنها كُتبت في بيئة **ليس فيها .NET SDK ولا Windows ولا الجهاز**. لذلك:
  - **لم تُترجَم ولم تُشغَّل ولم تُجرَّب على جهاز USB-Live2 الحقيقي.** ولهذا **لا يوجد ملف EXE جاهز** في هذه الحزمة؛ تبنيه بأمر واحد (القسم 2).
  - ما أُجري فقط: فحص ساكن للشيفرة (توازن الأقواس، وجود كل مفاتيح اللغة، سلامة مراجع الأعضاء بين الملفات) ومراجعة يدوية.
  - بعد أول بناء نفّذ اختبارات [TESTING.md](TESTING.md). عند أي خلل يكفي زر **نسخ معلومات التشخيص** في الإعدادات مع ملف `Settings\app.log` لإصلاحه بسرعة.
- **لا أعدك بصفر تأخير.** البرنامج يقلّل التأخير داخله (بلا ساعة عرض، أقل عدد ممكن من المخازن، عرض آخر إطار فقط، بلا أي معالجة للصورة)، أما التأخير الكلي فيعتمد على سائق الجهاز وUSB، ويجب قياسه (طريقة القياس في TESTING.md).
- **غير مؤكد:** أن سائق USB-Live2 يُظهر الجهاز كجهاز DirectShow (Video Capture). صفحات Hauppauge لا تذكر ذلك. إن لم يظهر الجهاز في القائمة فراجع «استكشاف الأخطاء».

## المتطلبات

- Windows 10 أو 11، 64-bit.
- جهاز USB-Live2 مع تعريفه (القسم 1).
- لتشغيل البرنامج: **لا حاجة لتثبيت .NET** (الملف مستقل Self-Contained).
- لبنائه من المصدر: .NET 8 SDK أو أحدث، أو GitHub Actions (القسم 2).
- للتسجيل فقط: `ffmpeg.exe` (القسم 3). المعاينة واللقطات تعمل بدونه.

## 1) تثبيت تعريف الجهاز

الخطوات مأخوذة من صفحات Hauppauge الرسمية (قد تتغير الروابط والإصدارات، فتحقق منها):

1. افتح صفحة الدعم: <https://hauppauge.com/pages/support/support_usblive2.html>
2. نزّل **Hauppauge Capture** (الإصدار المذكور فيها عند كتابة هذا الدليل 43356، حجمه نحو 86 MB):
   <https://s3.amazonaws.com/hauppauge/capture/hauppaugecapture_1_2_43356.exe>
3. **احفظ** الملف ثم شغّله من مجلد التنزيلات (لا تختر «Run» مباشرة من المتصفح). إن ظهرت نافذة SmartScreen فاختر *More info* ثم *Run anyway*.
4. تعريف الجهاز نفسه منقول إلى صفحة تعريفات Windows عند Hauppauge: <https://www.hauppauge.com/pages/support/support.html#win10> (تغطي الموديل القديم 122000 والجديد 122020).
5. **أعد تشغيل Windows** بعد التثبيت، ثم وصّل الجهاز (أو افصله ووصّله من جديد). يُفضَّل منفذ USB مباشر في الحاسوب وليس موزّعاً (Hub).
6. إن لم تظهر صورة من مدخل S-Video: تعرض Hauppauge في الصفحة نفسها تعريفاً خاصاً بمشاكل S-Video (الملف `WinTV-soloHDdualHDquadHD_USB-Live2_Model122020_5_2025_0612_43164-Win7-8-5_2020_0406_38125.exe`) ثم إعادة تشغيل. الصفحة لا تؤكد صراحةً دعمه لـ Windows 10/11، فاستعمله فقط إن احتجته.
7. **تحقق:** في إدارة الأجهزة (Device Manager) يجب أن يظهر الجهاز بلا علامة تعجب. ثم افتح برنامجاً آخر يعتمد DirectShow (مثل OBS Studio ← *Video Capture Device*، أو AMCap) وتأكد أن الجهاز يظهر فيه. **إن لم يظهر هناك فلن يظهر في هذا البرنامج.**
8. أغلق **Hauppauge Capture** وأي برنامج آخر يستخدم الجهاز قبل تشغيل هذا البرنامج؛ فجهاز الالتقاط يخدم عادةً برنامجاً واحداً في كل مرة.

> تذكر صفحة Hauppauge أن مؤشر LED الأخضر على الجهاز يبقى مطفأً إذا كان الكابل في S-Video والمصدر المختار Composite. اختر المصدر الصحيح من قائمة «مصدر الفيديو» في البرنامج.

## 2) الحصول على ملف EXE

### أ) على جهاز Windows (الأسهل)

1. ثبّت **.NET 8 SDK (x64)**: <https://dotnet.microsoft.com/download>
2. انقر مرتين على `build.bat` (أو: `powershell -ExecutionPolicy Bypass -File build.ps1`).
3. الناتج: `dist\Hauppauge Live Capture Studio\Hauppauge Live Capture Studio.exe` ومعه `ffmpeg\ffmpeg.exe` إن نجح التنزيل التلقائي.
   - `build.bat -SkipFfmpeg` يبني بدون تنزيل ffmpeg، و`build.bat -Clean` يمسح الناتج السابق أولاً.

### ب) بدون تثبيت أي شيء: GitHub Actions

1. ارفع محتوى المجلد إلى مستودع GitHub (يُفضَّل Private).
2. تبويب **Actions** ← *Build Windows EXE* ← *Run workflow*.
3. نزّل الـ Artifact: ملف ZIP يحوي الـ EXE (ومعه ffmpeg).

### ج) Visual Studio 2022

افتح `HauppaugeLiveCaptureStudio.sln` ثم Build. وللنشر المستقل (Publish Self-Contained, win-x64) من سطر الأوامر:

```
dotnet publish src\HauppaugeLiveCaptureStudio\HauppaugeLiveCaptureStudio.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## 3) FFmpeg (للتسجيل فقط)

يسجّل البرنامج بتشغيل `ffmpeg.exe` كعملية منفصلة تصلها الإطارات الخام عبر الأنبوب (stdin)، والمعاينة لا تعتمد عليه إطلاقاً. يبحث البرنامج عن `ffmpeg.exe` بهذا الترتيب: المسار المحدد في الإعدادات ← `ffmpeg\ffmpeg.exe` بجانب البرنامج ← `ffmpeg.exe` بجانبه ← `tools\` ← `ffmpeg\bin\` ← متغير PATH.

- يلزم مُرمِّز H.264: `libx264` (مفضّل) أو `h264_mf` (من Windows). نسخ **gpl** و**essentials** المعروفة تحتويه.
- سكربت `tools\fetch-ffmpeg.ps1` ينزّل نسخة جاهزة (ويستعمله `build.ps1` تلقائياً).
- **ترخيص:** النسخ المحتوية على libx264 مرخّصة GPL. تُنزَّل على جهازك ولا تأتي مع هذا المشروع. إن وزّعت البرنامج مع ffmpeg لغيرك فالتزم بشروط GPL.

## 4) الاستخدام

1. وصّل مصدر الفيديو (الكابل الأصفر = Composite، أو S-Video) ثم شغّل البرنامج. يظهر الجهاز في «جهاز الالتقاط» ويتحول المؤشر إلى **متصل**. زر «تحديث» يعيد البحث عن الأجهزة.
2. اختر **مصدر الفيديو** (Composite / S-Video) والدقة ومعدل الإطارات. القوائم تُملأ من إمكانات الجهاز الفعلية كما يعلنها السائق. تحت الشاشة يظهر الحجم والمعدل الفعليان.
3. اضغط **بدء البث (START LIVE)**.
4. **التقاط صورة (SNAPSHOT):** اكتب الاسم واختر JPG أو PNG. تُحفظ تلقائياً في `Pictures` بأعلى جودة يعطيها المصدر (JPG بجودة 100 أو PNG دون فقد). إن وُجد الاسم يُضاف رقم `(1)` ولا يُستبدل أي ملف. تظهر رسالة نجاح، وبالنقر عليها يُفتح الملف في Explorer. تعمل أثناء التسجيل.
5. **التسجيل:** اكتب الاسم (والتاريخ والوقت اختياريان) ثم **بدء التسجيل (START RECORDING)**. تظهر شارة حمراء **REC** ومؤقت. يُحفظ الملف في `Videos` بصيغة MP4/H.264 **بدون صوت**. **إيقاف التسجيل (STOP RECORDING)** يُنهي الملف. البث لا يتوقف عند البدء ولا عند الإيقاف. تسجيل واحد فقط في كل مرة، ولا يُستبدل أي تسجيل سابق.
6. **ملء الشاشة:** زر FULL SCREEN أو **F11** أو النقر المزدوج على الصورة. للخروج **Esc** أو زر EXIT FULL SCREEN. في ملء الشاشة يظهر شريط عائم (التقاط، تسجيل، مؤقت، خروج) عند تحريك الفأرة ثم يختفي.
7. **شكل الصورة:** تلقائي (4:3 لفيديو SD) أو بكسلات مربعة أو 16:9 أو ملء النافذة. يؤثر على العرض، وفي حالتي «تلقائي» و«16:9» يُوسَم الـ MP4 بنسبة العرض نفسها دون تغيير البكسلات.
8. **اللغة:** زر اللغة في الشريط العلوي (EN / ع). **الإعدادات:** مجلد الحفظ، مسار ffmpeg، جودة التسجيل، MP4 آمن (يبقى الملف صالحاً بعد انقطاع الكهرباء)، بدء البث تلقائياً، ونسخ معلومات التشخيص.

يعرض سطر المعلومات: الحجم، المعدل الفعلي، الإطارات المفقودة في التسجيل (يجب أن تبقى 0)، و«تأخير العرض» وهو الزمن داخل البرنامج فقط بين وصول الإطار من السائق ورسمه على الشاشة، وليس التأخير الكلي من الكاميرا إلى الشاشة.

## 5) المجلدات

```
Documents\Hauppauge Capture Studio\     (تُنشأ تلقائياً؛ يمكن تغيير موضعها من الإعدادات)
  Pictures\    اللقطات (JPG / PNG)
  Videos\      التسجيلات (MP4)
  Settings\    settings.json و app.log
```

## 6) استكشاف الأخطاء

| العَرَض | ما تفعله |
|---|---|
| الجهاز لا يظهر | ثبّت التعريف (القسم 1)، جرّب منفذ USB آخر، اضغط «تحديث». افحصه في OBS أو AMCap. إن لم يظهر هناك فالمشكلة في التعريف لا في البرنامج. |
| «لا تصل إطارات فيديو» | تحقق من الكابل وتشغيل المصدر واختيار Composite/S-Video الصحيح وأن الدقة تطابق نظام المصدر (NTSC 720×480 أو PAL 720×576)، وأن برنامجاً آخر لا يستخدم الجهاز. |
| فشل بدء البث | اقرأ نص الرسالة، وأغلق Hauppauge Capture وأي برنامج آخر يستخدم الجهاز. |
| التسجيل لا يبدأ | ffmpeg غير موجود أو بلا مُرمِّز H.264 (الإعدادات تعرض الحالة). التفاصيل في `Settings\app.log`. |
| خطوط «تمشيط» أثناء الحركة | الفيديو التماثلي متشابك (interlaced). البرنامج لا يعالج الصورة عمداً ولا يزيل التشابك. |
| تحذير SmartScreen | الـ EXE غير موقّع رقمياً. اختر *More info* ثم *Run anyway*. |
| تأخير ملحوظ | وصّل الجهاز بمنفذ مباشر، أغلق البرامج الثقيلة، وقِس التأخير بالطريقة في TESTING.md. جزء من التأخير داخل السائق ولا يتحكم به البرنامج. |

عند أي مشكلة: **الإعدادات ← نسخ معلومات التشخيص** ثم أرسل النص مع `Settings\app.log`.

## 7) حدود معروفة

- لم يُبنَ ولم يُختبر على الجهاز الحقيقي بعد (انظر الحالة أعلاه).
- لا يزيل التشابك (Deinterlace) ولا يعالج الصورة، حفاظاً على أقل تأخير.
- الصوت غير مدعوم عمداً: لا يُوصَل أي مسار صوت في الرسم البياني، ويعمل ffmpeg بالخيار `-an`.
- جهاز واحد في كل مرة، ونظام Windows 10/11 بنمط x64 فقط.

## 8) هيكل المشروع (للمطوّر)

```
src/HauppaugeLiveCaptureStudio/
  Core/        المسارات، الإعدادات، تسمية الملفات بلا استبدال، اللغات، السجل، خيط MTA
  DirectShow/  واجهات COM مكتوبة يدوياً (بلا مكتبات خارجية)، بناء الرسم البياني، المحرك
  Media/       FrameHub (توزيع الإطارات)، FfmpegRecorder، SnapshotService
  UI/          النافذة الرئيسية، ملء الشاشة، الإعدادات، عنصر عرض الفيديو
```

مسار الالتقاط: كاميرا ← السائق ← مرشّح الالتقاط ← SampleGrabber (RGB32، بلا ساعة عرض) ← **FrameHub**. يُنسخ كل إطار مرة واحدة في مخزن مُعاد الاستخدام ثم يوزَّع على ثلاثة مستهلكين مستقلين: **المعاينة** (آخر إطار فقط)، و**اللقطات** (آخر إطار عند الطلب)، و**المسجِّل** (طابور وخيط وعملية ffmpeg خاصة به بأولوية أقل). إن تأخر ffmpeg تُسقَط إطارات الطابور الخاص بالتسجيل فقط ويُعرض العداد، ولا تتأثر المعاينة.
